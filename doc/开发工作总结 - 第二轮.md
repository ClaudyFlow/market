## 一、修复的问题

### 1.1 编译错误修复

#### @RateLimiter 注解参数修复
**问题**: 注解使用 `limit()` 方法，但实际应为 `maxRequests()` 和 `timeout()`

**修复文件**:
- `AdminOrderController.java`
- `CartController.java`
- `ProductController.java`
- `ShopController.java`

**修复内容**:
```java
// 修复前
@RateLimiter(key = "'export_orders'", limit = 5, timeUnit = ...)

// 修复后
@RateLimiter(key = "'export_orders'", maxRequests = 5, timeout = 60, timeUnit = ...)
```

#### UserNotificationResponse DTO 修复
**问题**: Lombok @Data 注解未生效，缺少 Setter 方法

**解决方案**: 手动添加完整的 Getter/Setter 方法和 Builder 模式

```java
public class UserNotificationResponse {
    // 字段声明
    private Long id;
    private Long userId;
    // ... 其他字段
    
    // 构造函数
    public UserNotificationResponse() {}
    
    // Getter 和 Setter 方法
    public Long getId() { return id; }
    public void setId(Long id) { this.id = id; }
    // ... 其他 Setter
    
    // Builder 模式
    public static Builder builder() { return new Builder(); }
    
    public static class Builder {
        // Builder 实现
    }
}
```

#### CouponController 返回类型修复
**问题**: `getAvailableCoupons` 返回类型不匹配

**修复**: 将返回类型从 `List<Coupon>` 改为 `List<UserCoupon>`

#### UserNotificationServiceImpl 方法调用修复
**问题**: Repository 方法不存在或参数不匹配

**修复**:
- `findByUserIdAndIsReadFalse` 添加 Pageable 参数
- `findByUserIdAndCreatedAtBefore` 改用分页查询替代

### 1.2 文件清理

**删除重复文件**:
- `backend/src/main/java/com/market/service/UserNotificationServiceImpl.java` (重复文件)
