## 📖 1. 概述

### 1.1 数据库选型
- **主数据库**: PostgreSQL 14+
- **开发/测试**: H2 内存数据库
- **缓存**: Redis 7.x

### 1.2 设计原则
- 遵循第三范式 (3NF)
- 合理使用索引优化查询
- 外键约束保证数据完整性

## 🗄️ 2. 核心数据表

### 2.1 用户表 (users)

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO | 用户ID |
| username | VARCHAR(50) | UNIQUE, NOT NULL | 用户名 |
| email | VARCHAR(100) | UNIQUE | 邮箱 |
| password_hash | VARCHAR(255) | NOT NULL | 密码哈希 |
| phone | VARCHAR(20) | UNIQUE | 手机号 |
| avatar_url | VARCHAR(255) | | 头像URL |
| points | INT | DEFAULT 0 | 积分 |
| created_at | TIMESTAMP | NOT NULL | 创建时间 |
| updated_at | TIMESTAMP | NOT NULL | 更新时间 |

### 2.2 商品表 (products)

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO | 商品ID |
| name | VARCHAR(200) | NOT NULL | 商品名称 |
| description | TEXT | | 商品描述 |
| price | DECIMAL(10,2) | NOT NULL | 价格 |
| stock | INT | DEFAULT 0 | 库存 |
| category_id | BIGINT | FK | 分类ID |
| shop_id | BIGINT | FK | 店铺ID |
| status | INT | DEFAULT 1 | 状态: 0下架 1上架 |
| created_at | TIMESTAMP | NOT NULL | 创建时间 |

### 2.3 订单表 (orders)

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO | 订单ID |
| order_no | VARCHAR(50) | UNIQUE | 订单号 |
| user_id | BIGINT | FK | 用户ID |
| total_amount | DECIMAL(10,2) | NOT NULL | 订单总额 |
| status | INT | NOT NULL | 订单状态 |
| shipping_address | TEXT | | 收货地址 |
| remark | VARCHAR(500) | | 备注 |
| created_at | TIMESTAMP | NOT NULL | 创建时间 |

### 2.4 购物车表 (cart_items)

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO | 购物车项ID |
| user_id | BIGINT | FK, NOT NULL | 用户ID |
| product_id | BIGINT | FK, NOT NULL | 商品ID |
| quantity | INT | NOT NULL | 数量 |
| selected | BOOLEAN | DEFAULT true | 是否选中 |
| created_at | TIMESTAMP | NOT NULL | 创建时间 |

### 2.5 优惠券表 (coupons)

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO | 优惠券ID |
| name | VARCHAR(100) | NOT NULL | 优惠券名称 |
| discount_amount | DECIMAL(10,2) | | 折扣金额 |
| min_amount | DECIMAL(10,2) | | 最低消费 |
| start_time | TIMESTAMP | | 开始时间 |
| end_time | TIMESTAMP | | 结束时间 |
| total_count | INT | | 发放总量 |
| used_count | INT | DEFAULT 0 | 已使用量 |

### 2.6 评价表 (reviews)

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO | 评价ID |
| user_id | BIGINT | FK | 用户ID |
| product_id | BIGINT | FK | 商品ID |
| order_id | BIGINT | FK | 订单ID |
| rating | INT | 1-5 | 评分 |
| content | TEXT | | 评价内容 |
| created_at | TIMESTAMP | | 创建时间 |

### 2.7 通知表 (user_notifications)

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO | 通知ID |
| user_id | BIGINT | FK | 用户ID |
| title | VARCHAR(200) | | 通知标题 |
| content | TEXT | | 通知内容 |
| type | INT | | 通知类型 |
| is_read | BOOLEAN | DEFAULT false | 是否已读 |
| created_at | TIMESTAMP | | 创建时间 |

## 📊 3. 表关系

```
users (1) ──────< (N) orders
users (1) ──────< (N) cart_items
users (1) ──────< (N) reviews
users (1) ──────< (N) user_notifications

products (1) ───< (N) cart_items
products (1) ───< (N) reviews
products (1) ───< (N) order_items

orders (1) ─────< (N) order_items
```

---

## 🔍 4. 索引策略

| 表名 | 索引字段 | 索引类型 | 用途 |
|------|---------|---------|------|
| users | username, email | UNIQUE | 快速查询用户 |
| products | category_id, status | INDEX | 分类筛选 |
| orders | user_id, created_at | INDEX | 用户订单查询 |
| cart_items | user_id | INDEX | 购物车查询 |
| reviews | product_id | INDEX | 商品评价列表 |
