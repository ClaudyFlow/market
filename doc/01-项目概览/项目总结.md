## 🏗️ 技术架构

### 后端技术栈

```
Spring Boot 3.4.0
├── Spring Security (安全认证)
├── Spring Data JPA (数据访问)

├── Spring Actuator (监控)
├── JWT (Token 认证)

```

```
Vue 3 (组合式 API)
```

2. **BusinessException.java**
   - 问题：Lombok `@Data` 注解未正确生成 getter
   - 修复：手动添加 `getCode()` 方法

3. **GlobalExceptionHandler.java**
   - 问题：访问 `BusinessException.code` 字段
   - 修复：使用 `getCode()` 方法
