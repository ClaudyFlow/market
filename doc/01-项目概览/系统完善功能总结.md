## 一、支付系统（预留接口）⭐⭐⭐

### 1.1 后端新增文件

| 文件 | 路径 | 说明 |
|------|------|------|
| `Payment.java` | `backend/entity/` | 支付记录实体 |
| `PaymentRefund.java` | `backend/entity/` | 退款记录实体 |
| `PaymentRepository.java` | `backend/repository/` | 支付数据访问层 |
| `PaymentRefundRepository.java` | `backend/repository/` | 退款数据访问层 |
| `PaymentService.java` | `backend/service/` | 支付服务 |
| `PaymentController.java` | `backend/controller/` | 支付控制器 |

### 1.2 支付接口列表

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/payment/create` | 创建支付单 |
| POST | `/api/payment/callback/{method}` | 模拟支付回调（预留） |
| GET | `/api/payment/status/{paymentNo}` | 查询支付状态 |
| GET | `/api/payment/order/{orderNo}` | 根据订单号查询支付单 |
| POST | `/api/payment/refund` | 申请退款 |
| GET | `/api/payment/refund/status/{refundNo}` | 查询退款状态 |
| GET | `/api/payment/refund/list` | 获取用户退款列表 |
| POST | `/api/payment/refund/approve` | 审核退款（商家/管理员） |
| POST | `/api/payment/mock-pay/{paymentNo}` | 模拟支付（测试用） |

### 1.3 前端新增组件

| 组件 | 路径 | 说明 |
|------|------|------|
| `PaymentDialog.vue` | `frontend/src/user/components/` | 支付弹窗组件 |
| `PaymentResult.vue` | `frontend/src/user/components/` | 支付结果页组件 |

### 1.4 支持的支付方式（模拟）

- **WECHAT** - 微信支付（预留接口）
