## 📖 1. 概述

### 1.1 系统定位
购物商城系统是一个基于现代 Web 技术的全栈电商平台，采用前后端分离架构。

### 1.2 设计原则
- 高内聚、低耦合
- RESTful API 设计
- 前后端独立部署
- 安全性优先

## 🏗️ 2. 系统架构

### 2.1 整体架构

```
┌─────────────────────────────────────────┐
│            客户端（浏览器）               │
└──────────────┬──────────────────────────┘
               │ HTTP/HTTPS
┌──────────────▼──────────────────────────┐
│              Nginx 反向代理               │
└──────┬───────────────────┬──────────────┘
       │                   │
┌──────▼──────┐    ┌───────▼──────────────┐
│  前端静态文件 │    │   后端 API 服务       │
│  (Port 80)  │    │   (Port 8080)        │
└─────────────┘    └───┬──────────┬───────┘
                       │          │
              ┌────────▼──┐  ┌───▼────────┐
              │ PostgreSQL│  │   Redis    │
              │  Database │  │   Cache    │
              └───────────┘  └────────────┘
```

## 🔐 4. 安全架构

### 4.1 认证流程
```
用户登录 → 验证身份 → 生成JWT → 返回Token → 后续请求携带Token → 验证Token
```

### 4.2 权限控制
- 公开接口: `/api/auth/**`, `/api/product/**`
- 认证接口: 需要 JWT Token
- 管理员接口: `/api/admin/**` 需要 ADMIN 角色
