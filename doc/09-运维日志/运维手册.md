## 3. 日志管理

### 3.1 日志位置
| 组件 | 日志路径 | 说明 |
|------|---------|------|
| 后端 | `logs/market.log` | 应用日志 |
| Nginx | `/var/log/nginx/` | 访问/错误日志 |
| PostgreSQL | `/var/log/postgresql/` | 数据库日志 |
| Redis | `/var/log/redis/` | 缓存日志 |

### 3.2 日志轮转配置
```bash
# /etc/logrotate.d/market
/var/log/market/*.log {
    daily
    rotate 30
    compress
    delaycompress
    missingok
    notifempty
    create 0644 market market
    sharedscripts
    postrotate
        systemctl restart market-backend
    endscript
}
```

### 3.3 日志查询
```bash
# 查看最近错误
tail -f logs/market.log | grep ERROR

# 搜索特定用户操作
grep "user_id=123" logs/market.log

# 统计API调用次数
grep "API_CALL" logs/market.log | wc -l
```

## 4. 数据备份

### 4.1 数据库备份

#### 全量备份（每天凌晨2点）
```bash
#!/bin/bash
# backup.sh
BACKUP_DIR="/backup/postgresql"
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_FILE="$BACKUP_DIR/market_$DATE.sql"

pg_dump -U market -h localhost market > $BACKUP_FILE
gzip $BACKUP_FILE

# 保留30天备份
find $BACKUP_DIR -name "*.sql.gz" -mtime +30 -delete
```

#### 恢复数据库
```bash
gunzip market_20260406_020000.sql.gz
psql -U market -h localhost market < market_20260406_020000.sql
```

### 4.2 Redis 备份
```bash
# 配置自动保存
# redis.conf
save 900 1
save 300 10
save 60 10000

# 手动保存
redis-cli BGSAVE
```

### 4.3 备份验证
```bash
#!/bin/bash
# verify_backup.sh
BACKUP_FILE=$1
gunzip -t $BACKUP_FILE
if [ $? -eq 0 ]; then
    echo "备份文件完整"
else
    echo "备份文件损坏"
fi
```

## 5. 日常运维操作

### 5.1 服务启停
```bash
# 后端服务
sudo systemctl start market-backend
sudo systemctl stop market-backend
sudo systemctl restart market-backend
sudo systemctl status market-backend

# Nginx
sudo systemctl restart nginx

# PostgreSQL
sudo systemctl restart postgresql

# Redis
sudo systemctl restart redis
```

### 5.2 缓存清理
```bash
# 清理Redis缓存
redis-cli FLUSHDB

# 清理特定缓存
redis-cli KEYS "product:*" | xargs redis-cli DEL
```

### 5.3 数据库维护
```sql
-- 分析表统计信息

-- 检查数据库大小
SELECT pg_size_pretty(pg_database_size('market'));
```

## 6. 故障处理

### 6.1 常见问题

#### 问题1: 服务无法启动
```bash
# 检查端口占用
netstat -tulpn | grep :8080

# 检查日志
tail -f logs/market.log

# 检查数据库连接
pg_isready -h localhost -p 5432
```

#### 问题2: 数据库连接失败
```bash
# 检查PostgreSQL状态
sudo systemctl status postgresql

# 检查连接配置
cat backend/src/main/resources/application.properties | grep datasource

# 测试连接
psql -U market -h localhost -d market -c "SELECT 1"
```

#### 问题3: Redis连接失败
```bash
# 检查Redis状态
redis-cli ping

# 检查配置
cat backend/src/main/resources/application.properties | grep redis
```

#### 问题4: 磁盘空间不足
```bash
# 检查磁盘使用
df -h

# 清理日志
find /var/log -name "*.log" -mtime +7 -delete

# 清理临时文件
rm -rf /tmp/market/*
```

### 6.2 应急响应流程
```
1. 发现问题 → 监控告警 / 用户反馈
2. 确认问题 → 查看日志、监控
3. 隔离问题 → 确定影响范围
4. 解决问题 → 修复 / 回滚 / 重启
5. 验证修复 → 功能测试
6. 记录总结 → 更新故障知识库
```

## 7. 安全管理

### 7.1 防火墙配置
```bash
# 只开放必要端口
sudo ufw allow 80/tcp    # HTTP
sudo ufw allow 443/tcp   # HTTPS
sudo ufw allow 22/tcp    # SSH
sudo ufw enable
```

### 7.2 安全更新
```bash
# 定期更新系统
sudo apt update && sudo apt upgrade -y

# 更新应用
git pull origin main
mvn clean package -DskipTests
sudo systemctl restart market-backend
```

### 7.3 访问控制
- 数据库: 只允许应用服务器IP访问
- Redis: 设置密码，禁用危险命令
- SSH: 使用密钥登录，禁用密码登录

## 8. 性能优化

### 8.1 JVM 参数优化
```bash
# 启动参数
java -Xms2g -Xmx4g \
     -XX:+UseG1GC \
     -XX:MaxGCPauseMillis=200 \
     -jar market.jar
```

### 8.2 数据库优化
```sql
-- 添加索引
CREATE INDEX idx_orders_user_id ON orders(user_id);
CREATE INDEX idx_products_category ON products(category_id, status);

-- 查询优化
EXPLAIN ANALYZE SELECT * FROM orders WHERE user_id = 123;
```

### 8.3 Nginx 优化
```nginx
# 开启gzip压缩
gzip on;
gzip_types text/plain application/json application/javascript text/css;

# 静态资源缓存
location ~* \.(jpg|jpeg|png|gif|ico|css|js)$ {
    expires 30d;
    add_header Cache-Control "public, immutable";
}
```
