## 三、核心技术创新亮点

### 3.1 【区块链风格购物记录】

**创新点**：将区块链思想融入消费记录，实现类似Git提交风格的时间线展示，每笔操作生成哈希值和"已验证"标签。

**技术实现**：
- 前端 el-timeline 时间线组件展示
- 每条记录包含：时间戳 + 操作描述 + 哈希值 + 验证状态
- 哈希生成算法：`hash = f(订单号, 时间戳, 操作类型, 前一区块哈希)`
- 类似区块链的链式结构，数据防篡改

**核心代码**：
```typescript
const generateHash = (data: string): string => {
  let hash = 0
  for (let i = 0; i < data.length; i++) {
    const char = data.charCodeAt(i)
    hash = ((hash << 5) - hash) + char
    hash = hash & hash
  }
  return Math.abs(hash).toString(16).padStart(8, '0').toUpperCase()
}
```

**优势**：
- 可视化直观，类似Git提交记录
- 哈希验证，数据可追溯
- 用户信任度高，交易纠纷可回溯

| 1 | 白银会员 | 95% | 1,000 | 10 |
| 2 | 黄金会员 | 92% | 5,000 | 20 |

### 3.3 【智能抽奖系统】

**创新点**：概率可控算法 + 库存动态调整 + Redis分布式锁防重复。

**核心算法**：
```java
// 库存动态调整概率
public BigDecimal adjustProbability(LotteryPrize prize) {
    BigDecimal baseProb = prize.getBaseProbability();
    int remaining = prize.getRemainingStock();
    int total = prize.getTotalStock();

    // 库存不足时降低概率，充足时提高
    BigDecimal factor = new BigDecimal(remaining)
        .divide(new BigDecimal(total), 4, RoundingMode.HALF_UP);
    factor = factor.max(new BigDecimal("0.5")); // 最低50%
    factor = factor.min(new BigDecimal("1.5")); // 最高150%

    return baseProb.multiply(factor);
}
```

**防重复机制**：
- Redis分布式锁：`lottery:lock:{userId}:{activityId}`
- 每日抽奖次数限制：Redis计数器

**优势**：
- 奖池不会一次性被掏空
- 保证抽奖公平性
- 概率可控可调

### 3.5 【物流追踪系统】

**创新点**：实时轨迹 + 预计送达时间计算 + 异常状态告警。

**ETA算法**：
```java
// 预计送达 = 基础时间 × 距离系数 × 天气系数 × 节假日系数
public LocalDateTime calculateETA(LogisticsInfo info, String dest) {
    BigDecimal baseHours = new BigDecimal("48");

    BigDecimal distanceFactor = calculateDistance(info.getOrigin(), dest);
    BigDecimal weatherFactor = getWeatherFactor(dest);
    BigDecimal holidayFactor = getHolidayFactor();

    BigDecimal totalHours = baseHours
        .multiply(distanceFactor)
        .multiply(weatherFactor)
        .multiply(holidayFactor);

    return LocalDateTime.now().plusHours(totalHours.longValue());
}
```

**物流状态**：PENDING → IN_TRANSIT → OUT_FOR_DELIVERY → DELIVERED

**优势**：
- 物流透明可查
- 预计时间准确
- 异常主动告警
