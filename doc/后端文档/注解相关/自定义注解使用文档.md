# 自定义注解系统 - 完整文档

## 📋 概述

本项目实现了 14 个自定义注解，分为六类：

| 类别 | 注解 | 实现方式 |
|------|------|----------|
| **可用性** | `@ApiAvailable` | AOP 切面 |
| **弃用管理** | `@DeprecatedApi` | AOP 切面 |
| **性能优化** | `@Cacheable` | AOP 切面 |
| **容错处理** | `@Retryable` | AOP 切面 |
| **并发控制** | `@RateLimiter` | 拦截器 |
| | `@Idempotent` | AOP 切面 |
| | `@DistributedLock` | AOP 切面 |
| **数据安全** | `@SensitiveData` | ResponseBodyAdvice |
| | `@DataScope` | AOP 切面 |
| **健康检查** | `@ApiHealthCheck` | 配置注解 |
| **审计日志** | `@AuditLog` | AOP 切面 |

## 1. @Cacheable - 缓存注解

### 功能说明
用于标记需要缓存结果的方法，支持 SpEL 表达式生成缓存 key，可配置过期时间。

### 注解参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `cacheName` | String | "default" | 缓存名称，用于分组管理 |
| `key` | String | "" | 缓存 key（支持 SpEL 表达式） |
| `expire` | long | 300 | 缓存过期时间 |
| `timeUnit` | TimeUnit | SECONDS | 时间单位 |
| `ignoreNull` | boolean | true | 是否忽略 null 值 |
| `condition` | String | "" | 缓存条件（SpEL 表达式） |
| `unless` | String | "" | 不缓存的条件 |
| `description` | String | "" | 缓存描述 |

### 使用示例

```java
// 基础用法
@GetMapping("/product/{id}")
@Cacheable(key = "#id", cacheName = "products", expire = 300)
public Result<Product> getProduct(@PathVariable Long id) {
    return Result.success(productService.getById(id));
}

// 使用 SpEL 表达式
@GetMapping("/products")
@Cacheable(
    key = "'list_' + #page + '_' + #size",
    cacheName = "productLists",
    expire = 600
)
public Result<List<Product>> getProducts(
    @RequestParam int page,
    @RequestParam int size) {
    return Result.success(productService.list(page, size));
}

// 条件缓存（只缓存价格大于 0 的商品）
@Cacheable(
    key = "#id",
    cacheName = "products",
    condition = "#result.price > 0"
)
public Result<Product> getProduct(@PathVariable Long id) {
    ...
}

// 不缓存 null 值
@Cacheable(
    key = "#id",
    cacheName = "users",
    ignoreNull = true
)
public Result<User> getUser(@PathVariable Long id) {
    ...
}
```

### SpEL 表达式支持

| 变量 | 说明 |
|------|------|
| `#paramName` | 方法参数名 |
| `#param0`, `#param1` | 按索引访问参数 |
| `#result` | 方法返回值（用于 condition/unless） |
| `#method` | 方法名 |
| `#target` | 目标对象 |

## 2. @Retryable - 重试注解

### 功能说明
用于标记需要自动重试的方法，支持指数退避、异常过滤、自定义重试条件。

### 注解参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `maxAttempts` | int | 3 | 最大重试次数（包括首次） |
| `delay` | long | 1000 | 重试间隔（毫秒） |
| `multiplier` | double | 1.0 | 延迟乘数（指数退避） |
| `maxDelay` | long | 10000 | 最大延迟时间 |
| `timeUnit` | TimeUnit | MILLISECONDS | 时间单位 |
| `include` | Class[] | {Exception} | 需要重试的异常类型 |
| `exclude` | Class[] | {} | 不需要重试的异常类型 |
| `condition` | String | "" | 自定义重试条件 |
| `failureHandler` | enum | THROW | 失败处理器 |
| `logEnabled` | boolean | true | 是否记录日志 |

### 失败处理器

| 处理器 | 说明 |
|--------|------|
| `THROW` | 抛出最后一次异常 |
| `RETURN_NULL` | 返回 null |
| `RETURN_DEFAULT` | 调用默认方法返回 |

### 使用示例

```java
// 基础重试（重试 3 次，每次间隔 1 秒）
@Retryable(maxAttempts = 3, delay = 1000)
public Result<String> callExternalApi() {
    return restTemplate.getForObject(url, String.class);
}

// 指数退避（1s, 2s, 4s）
@Retryable(
    maxAttempts = 4,
    delay = 1000,
    multiplier = 2.0
)
public Result<String> callWithBackoff() {
    ...
}

// 指定异常类型重试
@Retryable(
    maxAttempts = 3,
    include = {ResourceAccessException.class, TimeoutException.class}
)
public Result<String> callWithExceptionFilter() {
    ...
}

// 排除特定异常
@Retryable(
    maxAttempts = 3,
    include = {Exception.class},
    exclude = {IllegalArgumentException.class}
)
public Result<String> callWithExclusion() {
    ...
}

// 失败返回 null
@Retryable(
    maxAttempts = 3,
    failureHandler = Retryable.FailureHandler.RETURN_NULL
)
public Result<String> callWithFallback() {
    ...
}

// 自定义条件重试（只在尝试次数<=3 时重试）
@Retryable(
    maxAttempts = 5,
    condition = "#attempt <= 3"
)
public Result<String> callWithCondition() {
    ...
}
```

## 3. @AuditLog - 审计日志注解

### 功能说明
用于标记需要记录审计日志的操作，记录操作人、操作时间、操作内容、IP 地址等信息。

### 注解参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `module` | String | "" | 操作模块 |
| `action` | String | "" | 操作类型 |
| `description` | String | "" | 操作描述（支持 SpEL） |
| `recordParams` | boolean | true | 是否记录请求参数 |
| `recordResult` | boolean | false | 是否记录返回结果 |
| `recordResponseTime` | boolean | true | 是否记录响应时间 |
| `operatorId` | String | "#authentication?.name" | 操作人 ID |
| `operatorName` | String | "" | 操作人名称 |
| `businessId` | String | "" | 业务 ID（SpEL 表达式） |
| `businessType` | String | "" | 业务类型 |
| `logLevel` | enum | INFO | 日志级别 |
| `async` | boolean | true | 是否异步记录 |
| `ignoreExceptions` | Class[] | {} | 忽略的异常类型 |

### 日志级别

| 级别 | 说明 |
|------|------|
| `DEBUG` | 调试 |
| `INFO` | 信息 |
| `WARNING` | 警告 |
| `ERROR` | 错误 |

### 使用示例

```java
// 记录创建操作
@PostMapping
@AuditLog(
    module = "商品管理",
    action = "创建商品",
    description = "创建商品：#product.name",
    recordParams = true,
    recordResult = true
)
public Result<Product> create(@RequestBody Product product) {
    ...
}

// 记录更新操作
@PutMapping("/{id}")
@AuditLog(
    module = "商品管理",
    action = "更新商品",
    description = "更新商品 ID: #id",
    businessId = "#id",
    businessType = "PRODUCT"
)
public Result<Product> update(
    @PathVariable Long id,
    @RequestBody Product product) {
    ...
}

// 记录删除操作（警告级别）
@DeleteMapping("/{id}")
@AuditLog(
    module = "商品管理",
    action = "删除商品",
    logLevel = AuditLog.LogLevel.WARNING,
    businessId = "#id"
)
public Result<Void> delete(@PathVariable Long id) {
    ...
}

// 记录用户操作
@PostMapping("/action")
@AuditLog(
    module = "用户操作",
    action = "#actionType",
    operatorId = "#userId",
    description = "用户 #userId 执行操作：#actionType"
)
public Result<Void> recordAction(
    @RequestParam String userId,
    @RequestParam String actionType) {
    ...
}
```

### 审计日志输出示例

```
[审计日志] 模块：商品管理 | 操作：创建商品 | 状态：SUCCESS | 
操作人：admin | IP: 192.168.1.100 | 耗时：156ms | 
描述：创建商品：iPhone 15 | 参数：{"name":"iPhone 15","price":8999}
```

## 4. @Idempotent - 幂等性注解

### 功能说明
用于标记需要保证幂等性的操作，防止重复提交、重复处理。

### 注解参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `key` | String | "" | 幂等 key（支持 SpEL 表达式） |
| `expire` | long | 3600 | 过期时间 |
| `timeUnit` | TimeUnit | SECONDS | 时间单位 |
| `message` | String | "操作正在执行中" | 错误消息 |
| `throwException` | boolean | true | 是否抛出异常 |
| `cacheResult` | boolean | false | 是否缓存结果 |

### 使用示例

```java
// 防止重复提交订单
@PostMapping("/orders")
@Idempotent(key = "#order.userId + '_' + #order.productId", expire = 60)
public Result<Order> createOrder(@RequestBody Order order) {
    return Result.success(orderService.create(order));
}

// 缓存结果的幂等性
@Idempotent(
    key = "#userId",
    expire = 3600,
    cacheResult = true,
    message = "请求正在处理中"
)
public Result<UserInfo> getUserInfo(@PathVariable Long userId) {
    return Result.success(userService.getInfo(userId));
}
```

## 5. @DistributedLock - 分布式锁注解

### 功能说明
用于标记需要加锁执行的方法，支持可重入锁和读写锁。

### 注解参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `key` | String | "" | 锁 key（支持 SpEL 表达式） |
| `waitTime` | long | 5000 | 等待时间（毫秒） |
| `leaseTime` | long | 30000 | 锁持有时间（毫秒） |
| `timeUnit` | TimeUnit | MILLISECONDS | 时间单位 |
| `fair` | boolean | false | 是否公平锁 |
| `lockType` | enum | REENTRANT | 锁类型 |
| `retryCount` | int | 0 | 重试次数 |
| `message` | String | "获取锁失败" | 错误消息 |

### 锁类型

| 类型 | 说明 |
|------|------|
| `REENTRANT` | 可重入锁 |
| `READ` | 读锁 |
| `WRITE` | 写锁 |

### 使用示例

```java
// 可重入锁
@DistributedLock(key = "#userId", waitTime = 3000, leaseTime = 10000)
public Result<Void> updateUserInfo(@PathVariable Long userId, @RequestBody User user) {
    return Result.success();
}

// 读写锁（读）
@DistributedLock(key = "#productId", lockType = DistributedLock.LockType.READ)
public Result<Product> getProduct(@PathVariable Long productId) {
    return Result.success(productService.getById(productId));
}

// 读写锁（写）
@DistributedLock(key = "#productId", lockType = DistributedLock.LockType.WRITE)
public Result<Void> updateProduct(@PathVariable Long productId, @RequestBody Product product) {
    return Result.success();
}

// 带重试的锁
@DistributedLock(
    key = "#orderId",
    waitTime = 2000,
    retryCount = 3,
    retryInterval = 100
)
public Result<Void> processOrder(@PathVariable Long orderId) {
    return Result.success();
}
```

## 6. @SensitiveData - 敏感数据脱敏注解

### 功能说明
用于标记需要脱敏的字段或方法返回值，支持多种脱敏规则。

### 注解参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `type` | SensitiveType | DEFAULT | 脱敏类型 |
| `maskChar` | char | '*' | 脱敏字符 |
| `prefixLength` | int | 0 | 保留前缀长度 |
| `suffixLength` | int | 0 | 保留后缀长度 |

### 脱敏类型

| 类型 | 说明 | 脱敏规则 |
|------|------|----------|
| `PHONE` | 手机号 | 138****1234 |
| `ID_CARD` | 身份证 | 110101********1234 |
| `BANK_CARD` | 银行卡 | 6222****1234 |
| `EMAIL` | 邮箱 | abc****@gmail.com |
| `ADDRESS` | 地址 | 北京市**** |
| `NAME` | 姓名 | 张** |
| `PASSWORD` | 密码 | ****** |
| `CUSTOM` | 自定义 | 按 prefix/suffix 配置 |

### 使用示例

```java
// 实体类字段脱敏
public class User {
    @SensitiveData(type = SensitiveType.PHONE)
    private String phone;

    @SensitiveData(type = SensitiveType.ID_CARD)
    private String idCard;

    @SensitiveData(type = SensitiveType.EMAIL)
    private String email;

    @SensitiveData(type = SensitiveType.NAME)
    private String name;

    @SensitiveData(type = SensitiveType.PASSWORD)
    private String password;
}

// 方法返回值脱敏
@SensitiveData(type = SensitiveType.PHONE)
@GetMapping("/phone/{id}")
public String getUserPhone(@PathVariable Long id) {
    return "13800138000";
}

// 自定义脱敏（保留前 3 后 2）
@SensitiveData(type = SensitiveType.CUSTOM, prefixLength = 3, suffixLength = 2)
public String getSecretCode() {
    return "ABC12345XYZ";  // 输出：ABC*****YZ
}
```

## 7. @DataScope - 数据权限注解

### 功能说明
用于标记需要数据权限控制的方法，自动过滤用户只能访问其权限范围内的数据。

### 注解参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `deptAlias` | String | "" | 部门别名（用于 SQL 拼接） |
| `userAlias` | String | "" | 用户别名（用于 SQL 拼接） |
| `scopeType` | ScopeType | CUSTOM | 权限范围类型 |

### 权限范围类型

| 类型 | 说明 |
|------|------|
| `ALL` | 全部数据权限 |
| `DEPT` | 本部门数据权限 |
| `DEPT_AND_CHILD` | 本部门及子部门数据权限 |
| `SELF` | 仅本人数据权限 |
| `CUSTOM` | 自定义数据权限 |

### 使用示例

```java
// 仅本人数据
@DataScope(scopeType = ScopeType.SELF, userAlias = "u")
public List<User> getMyUsers() {
    return userService.list();
}

// 本部门数据
@DataScope(scopeType = ScopeType.DEPT, deptAlias = "d")
public List<Order> getDeptOrders() {
    return orderService.list();
}

// 本部门及子部门数据
@DataScope(
    scopeType = ScopeType.DEPT_AND_CHILD,
    deptAlias = "d",
    userAlias = "u"
)
public List<Product> getDeptProducts() {
    return productService.list();
}

// 在 Service 中使用数据权限上下文
public List<User> list() {
    DataScopeAspect.DataScopeContext scope = DataScopeAspect.getCurrentScope();
    String sqlFilter = scope.getSqlFilter();
    // 将 sqlFilter 添加到查询条件中
    return userMapper.selectListWithFilter(sqlFilter);
}
```

### 执行流程

```
请求 → @Retryable(重试包装)
     → @Cacheable(检查缓存)
        → 缓存命中 → 返回
        → 缓存未命中 → @AuditLog(记录开始)
           → 执行方法
           → @AuditLog(记录完成)
           → @Cacheable(写入缓存)
     → 返回结果
```

## 7. 最佳实践

### 缓存使用建议

1. **读多写少** 的数据适合缓存
2. **设置合理过期时间**，避免数据不一致
3. **使用有意义的 cacheName**，便于管理
4. **大数据量** 考虑分页缓存

### 重试使用建议

1. **幂等操作** 才使用重试
2. **指数退避** 避免雪崩
3. **排除业务异常**（如参数错误）
4. **设置最大重试次数**，避免无限重试

### 审计日志使用建议

1. **关键操作** 必须记录（增删改）
2. **敏感信息** 脱敏处理
3. **异步记录** 避免影响性能
4. **定期归档** 历史日志

### 幂等性使用建议

1. **POST/PUT/DELETE** 操作建议使用
2. **合理设置过期时间**，避免锁长时间不释放
3. **前端防重** + 后端幂等双重保障
4. **缓存结果** 适合查询密集型场景

### 分布式锁使用建议

1. **细粒度锁**，避免大锁影响并发
2. **设置超时时间**，避免死锁
3. **生产环境** 使用 Redis 分布式锁
4. **避免锁竞争**，合理设计业务

### 敏感数据脱敏使用建议

1. **手机号、身份证、银行卡** 必须脱敏
2. **生产环境** 开启脱敏
3. **测试环境** 可关闭脱敏便于调试
4. **自定义规则** 满足特殊需求

### 数据权限使用建议

1. **多租户系统** 必须使用
2. **部门数据隔离** 场景适用
3. **SQL 注入防护**，使用参数化查询
4. **权限缓存**，提升性能

## 8. 注意事项

| 问题 | 说明 |
|------|------|
| **AOP 失效** | 同类调用不触发切面，需通过 Spring 容器获取 |
| **缓存穿透** | 使用 `ignoreNull=false` 缓存空值 |
| **重试副作用** | 非幂等操作慎用重试 |
| **日志性能** | 大对象记录考虑异步 |
| **SpEL 性能** | 复杂表达式影响性能 |
| **锁超时** | 设置合理的 leaseTime |
| **脱敏性能** | 大批量数据考虑关闭脱敏 |
