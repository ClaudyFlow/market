# API 可用性检测注解 - 如何测试

## ⚡ 快速测试（推荐）

### 方法 1: 运行单元测试（无需启动服务）

在 IDE 中右键运行 `ApiAvailabilityIntegrationTest.java` 的 `main` 方法

或在命令行运行：
```bash
cd d:\market\backend\src\test\java
java com.market.aspect.ApiAvailabilityIntegrationTest
```

### 方法 2: 启动服务后运行测试脚本

```bash
# 1. 启动后端服务
mvn spring-boot:run -pl backend

# 2. 运行测试脚本
test-availability.bat
```

## 📋 测试端点列表

| 端点 | 说明 | 预期结果 |
|------|------|----------|
| `/api/test/availability/basic` | 基础测试 | 成功 |
| `/api/test/availability/database` | 数据库依赖检测 | 取决于数据库状态 |
| `/api/test/availability/redis` | Redis 依赖检测 | 取决于 Redis 状态 |
| `/api/test/availability/multi-dependencies` | 多依赖检测 | 取决于服务状态 |
| `/api/test/availability/throw-exception` | 失败抛异常 | 可能返回错误 |
| `/api/test/availability/continue-on-failure` | 失败继续执行 | 总是成功 |
| `/api/test/availability/timeout-test?delayMs=2000` | 超时测试 | 1 秒后返回超时错误 |
| `/api/test/availability/retry-test` | 重试机制测试 | 成功或重试 |
| `/api/test/availability/health-check` | 健康检查测试 | 成功 |
| `/api/test/availability/disabled` | 禁用检测测试 | 成功 |

## 🔍 验证功能是否生效

### 1. 查看日志

启动服务后，日志应显示：
```
INFO  API 可用性检测通过：com.market.controller.ApiAvailabilityTestController.basicTest
```

### 2. 测试超时

```bash
# 这个方法延迟 2 秒，但超时设置为 1 秒
# 应该在 1 秒后返回错误，而不是等待 2 秒
curl http://localhost:8080/api/test/availability/timeout-test?delayMs=2000
```

### 3. 测试依赖检测

```bash
# 如果数据库不可用，应该返回错误
curl http://localhost:8080/api/test/availability/database
```
