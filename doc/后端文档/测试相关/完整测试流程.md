## 🧪 第三阶段：集成测试（需要启动服务）

### 步骤 1: 启动后端服务

#### 方法 A: 使用 IDE（推荐）

**IntelliJ IDEA:**
1. 打开 `backend/src/main/java/com/market/MarketApplication.java`
2. 右键 → `Run 'MarketApplication.main()'`
3. 等待控制台显示：`Started MarketApplication in X seconds`

**Eclipse:**
1. 右键 `MarketApplication.java`
2. `Run As` → `Java Application`

#### 方法 B: 使用命令行

```bash
# 如果有 Maven
cd d:\market
mvn spring-boot:run -pl backend
```

## 🐛 常见问题排查

### Q1: 服务启动失败

**检查：**
```bash
# 查看端口占用
netstat -ano | findstr :8080

# 如果端口被占用，修改 application.properties
server.port=8081
```

### Q2: 404 Not Found

**解决：**
1. 确认服务已启动
2. 确认 URL 路径正确
3. 查看控制台是否有映射信息

### Q3: 连接被拒绝

**解决：**
1. 确认服务已完全启动（看到 `Started MarketApplication`）
2. 检查防火墙设置
3. 确认端口号正确

### Q4: 注解不生效

**检查：**
1. 方法上有 `@ApiAvailable` 注解
2. `ApiAvailabilityAspect` 类有 `@Aspect` 和 `@Component`
3. 查看日志是否有检测信息

### Q5: 超时测试不超时

**检查：**
1. `delayMs` 参数应大于 timeout 值
2. timeout 单位是毫秒
3. 查看日志确认超时信息
