## 🚀 2. 当前版本

### v1.0.0 (2026-04-06)

#### 新增功能
- ✅ 用户认证系统（登录/注册/JWT）
- ✅ 商品浏览与搜索（10+分类）
- ✅ 购物车完整功能（选中/全选/库存检查）
- ✅ 订单完整流程（创建/支付/取消/评价）
- ✅ 优惠券系统（领取/使用/管理）
- ✅ 用户中心（个人信息/地址/收藏/关注）
- ✅ 积分系统（签到/查询/兑换）
- ✅ VIP会员系统
- ✅ 论坛社区（发帖/评论/点赞）
- ✅ 在线客服（WebSocket实时聊天）
- ✅ 通知中心（系统/订单/活动通知）
- ✅ 幸运抽奖
- ✅ 购物评分反馈

#### 技术架构
- **前端**: Vue 3 + TypeScript + Element Plus + Vite
- **后端**: Spring Boot 3.4.0 + JPA + Spring Security + Redis
- **数据库**: PostgreSQL 14+ / H2 (开发)
- **三端分离**: 用户端/商家端/管理端

#### 已知问题
- ⚠️ cart.ts 有6处路径不匹配（待修复）
- ⚠️ 部分 vendor chunk 超过 500KB（性能优化）
- ⚠️ 通知中心页面UI待完善

#### 升级说明
- 首次发布，无需升级

## 🔄 5. 升级指南

### 从 v1.0.0 升级到 v1.1.0

#### 步骤1: 备份数据
```bash
# 备份数据库
pg_dump -U market market > backup_v1.0.0.sql

# 备份Redis
redis-cli BGSAVE
```

#### 步骤2: 更新代码
```bash
git pull origin v1.1.0
```

#### 步骤3: 更新依赖
```bash
# 后端
cd backend
mvnd clean install

# 前端
cd frontend
npm install
```

#### 步骤4: 数据库迁移
```bash
# 执行迁移脚本（如有）
```

#### 步骤5: 重启服务
```bash
# 重启后端
sudo systemctl restart market-backend

# 重新构建前端
cd frontend && npm run build
sudo systemctl restart nginx
```

#### 步骤6: 验证
- 运行测试用例
- 检查核心功能
- 查看日志确认无异常
