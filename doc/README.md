## 🛠️ 文档构建

### 环境要求

- [Typst](https://typst.app/) 0.11.0 或更高版本
- 中文字体支持（SimHei、SimSun 等）

### 编译 PDF

```bash
# 编译单个文档
typst compile 项目简介.typ
typst compile 前端功能介绍.typ
typst compile 部署配置指南.typ

# 或使用 watch 模式实时预览
typst watch 项目简介.typ
```

### 字体配置

文档使用以下中文字体：
- **SimHei**（黑体）- 标题
- **SimSun**（宋体）- 正文

请确保系统已安装上述字体，或在 Typst 配置中指定替代字体。

## 📝 文档规范

### 排版格式

- 纸张：A4
- 页边距：内侧 25mm，外侧 20mm，顶部 35mm，底部 30mm
- 正文字体：五号宋体（10.5pt）
- 标题字体：五号黑体（10.5pt）
- 行距：1.25 倍

### 页眉页脚

- 页眉：文档标题居中
- 页脚：日期居左，页码居右
- 目录页使用罗马数字页码
- 正文使用阿拉伯数字页码

### 更新维护

- 文档应随代码变更同步更新
- 重大功能变更需要更新相关文档
- 版本号应在文档中标注
- 最后更新日期应保持一致
