## 1. 概述

本文档提供购物商城系统的完整部署步骤，支持本地开发和生产环境部署。本项目采用本地依赖部署方式，不使用Docker容器化。

## 3. 本地开发部署

### 3.1 后端部署

#### 步骤1: 克隆项目
```bash
git clone <repository-url>
cd market
```

#### 步骤2: 安装本地依赖

**PostgreSQL 安装与配置:**
```bash
# Windows (使用 Chocolatey)
choco install postgresql-15

# 启动 PostgreSQL 服务
pg_ctl -D "C:\Program Files\PostgreSQL\data" start

# 创建数据库和用户
psql -U postgres
CREATE USER market WITH PASSWORD 'market';
CREATE DATABASE market OWNER market;
GRANT ALL PRIVILEGES ON DATABASE market TO market;
\q
```

**Redis 安装与配置:**
```bash
# Windows (使用 Chocolatey)
choco install redis-64

# 启动 Redis 服务
redis-server
```

#### 步骤3: 配置应用
编辑 `backend/src/main/resources/application.properties`:
```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/market
spring.datasource.username=market
spring.datasource.password=market
spring.data.redis.host=localhost
spring.data.redis.port=6379
spring.data.redis.password=
```

#### 步骤4: 初始化数据库
```bash
# 执行数据库初始化脚本
psql -U market -d market -f script/build/init-postgresql.sql
```

#### 步骤5: 启动后端
```bash
cd backend
mvn spring-boot:run
# 或使用启动脚本
./start_backend.bat  # Windows
```

访问: `http://localhost:8080`

### 3.2 前端部署

#### 步骤1: 安装依赖
```bash
cd frontend
npm install
```

#### 步骤2: 启动开发服务器
```bash
npm run dev
```

访问: `http://localhost:5173`

## 4. 生产环境部署

### 4.1 后端部署

#### 步骤1: 打包应用
```bash
cd backend
mvn clean package -DskipTests
```

#### 步骤2: 运行 JAR
```bash
java -jar backend/target/market-0.0.1-SNAPSHOT.jar \
  --spring.profiles.active=prod
```

#### 步骤3: 配置 systemd 服务
```ini
[Unit]
Description=Market Backend
After=network.target

[Service]
Type=simple
User=market
WorkingDirectory=/opt/market
ExecStart=/usr/bin/java -jar market.jar --spring.profiles.active=prod
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable market-backend
sudo systemctl start market-backend
```

### 4.2 前端部署

#### 步骤1: 构建生产版本
```bash
cd frontend
npm run build
```

#### 步骤2: 配置 Nginx
```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /var/www/market/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # 后端API代理
    location /api/ {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # WebSocket代理
    location /ws/ {
        proxy_pass http://localhost:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

#### 步骤3: 重启 Nginx
```bash
sudo nginx -t
sudo systemctl restart nginx
```
