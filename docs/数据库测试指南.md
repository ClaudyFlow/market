## 一、前置准备

### 1.1 安装 PostgreSQL

**Windows:**
1. 下载安装包：https://www.postgresql.org/download/windows/
2. 运行安装程序，记住设置的密码（默认用户名：postgres）
3. 安装完成后，PostgreSQL 服务会自动启动

**检查 PostgreSQL 是否运行:**
```bash
# 方式 1: 使用 pg_ctl
pg_ctl status

# 方式 2: 查看服务状态 (Windows)
sc query postgresql-x64-16

# 方式 3: 检查端口
netstat -ano | findstr :5432
```

### 1.2 创建数据库

```bash
# 方式 1: 使用命令行
createdb -U postgres market_db

# 方式 2: 使用 psql
psql -U postgres
CREATE DATABASE market_db;
\q

# 方式 3: 使用 pgAdmin
# 右键 Databases -> Create -> Database -> 输入 market_db
```

### 1.3 初始化数据库结构

```bash
# 方式 1: 使用 psql 执行 SQL 文件
psql -U postgres -d market_db -f docs/database.sql

# 方式 2: 在 psql 交互模式中执行
psql -U postgres -d market_db
\i docs/database.sql

# 方式 3: 使用 pgAdmin
# 打开 Query Tool -> 加载 database.sql -> 执行
```

## 三、使用 Spring Boot 后端测试

### 3.1 修改数据库配置

**方式 A: 使用 PostgreSQL 配置（推荐用于生产环境）**

1. 编辑 `backend/src/main/resources/application.properties`:
```properties
spring.profiles.active=postgresql
```

2. 确保 `application-postgresql.properties` 配置正确:
```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/market_db
spring.datasource.username=postgres
spring.datasource.password=你的密码
```

**方式 B: 继续使用 SQLite（开发环境）**
```properties
# 保持现有 SQLite 配置不变
spring.datasource.url=jdbc:sqlite:market.db
```

### 3.2 启动后端服务

```bash
cd backend

# Windows
mvnw spring-boot:run

# 或者使用 IDEA 直接运行 MarketApplication.java
```

### 3.3 检查启动日志

成功连接数据库时，日志中会显示:
```
Hibernate: create table users (...)
Hibernate: create table products (...)
...
Initialized JPA EntityManagerFactory for persistence unit 'default'
```

## 五、前端联调测试

### 5.1 启动前端开发服务器

```bash
cd frontend
npm run dev
```

### 5.2 访问前端页面

- 用户端：http://localhost:5173
- 商家端：http://localhost:5173/merchant
- 管理端：http://localhost:5173/admin

### 5.3 测试流程

1. **用户注册/登录**
   - 访问 http://localhost:5173/login
   - 点击注册，创建新用户
   - 检查数据库：`SELECT * FROM users ORDER BY id DESC LIMIT 1;`

2. **浏览商品**
   - 访问首页查看商品列表
   - 点击商品查看详情
   - 检查数据库：`SELECT * FROM products WHERE available = true;`

3. **加入购物车**
   - 登录状态下添加商品到购物车
   - 检查数据库：`SELECT * FROM cart_items;`

4. **创建订单**
   - 从购物车结算
   - 检查数据库：`SELECT * FROM orders ORDER BY id DESC LIMIT 1;`
   - 检查订单项：`SELECT * FROM order_items WHERE order_id = (SELECT MAX(id) FROM orders);`

5. **收藏/关注**
   - 收藏商品、关注店铺
   - 检查数据库：`SELECT * FROM favorites; SELECT * FROM follows;`

6. **发表评价**
   - 完成订单后评价商品
   - 检查数据库：`SELECT * FROM reviews ORDER BY id DESC LIMIT 1;`

## 六、常见问题排查

### 6.1 连接失败

**错误：Connection refused**
```bash
# 检查 PostgreSQL 服务是否启动
# Windows:
sc query postgresql-x64-16
net start postgresql-x64-16

# 检查端口
netstat -ano | findstr :5432
```

**错误：Authentication failed**
```bash
# 检查用户名密码是否正确
# 重置 postgres 用户密码：
psql -U postgres
ALTER USER postgres WITH PASSWORD '新密码';
```

### 6.2 表不存在

```bash
# 检查表是否创建
psql -U postgres -d market_db -c "\dt"

# 重新执行初始化脚本
psql -U postgres -d market_db -f docs/database.sql
```

### 6.3 Hibernate 自动建表问题

如果使用 `ddl-auto=update`，Hibernate 会自动创建表结构：

```properties
# 开发环境 - 自动更新表结构
spring.jpa.hibernate.ddl-auto=update

# 生产环境 - 不自动修改
spring.jpa.hibernate.ddl-auto=validate

# 首次初始化 - 创建并填充数据
spring.jpa.hibernate.ddl-auto=create
```
